# Blog Frontend Application

This is a simple blog fronted application.

## Description

This is a frontend implementation of a blog application. Users can login, authenticate via JWT, and manage blog posts by performing CRUD(Create, Read, Update and Delete).

## Technologies Used

- React: Frontend library
- React router: Navigation and routing
- Axios: HTTP client for API requests

## Features

1. **User Authentication:**

- Register and login pages
- Store JWT tokens in localStorage
- Redirect to login for unauthorized access

2. **Post Management:**

- View all blog posts
- Create, Read, Update and Delete posts
- Display success/error messages for actions

3. **Dynamic Routing:**

- Private routes for authenticated users
